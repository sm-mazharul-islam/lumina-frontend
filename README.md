## 🚀 Key Features

- **Neural Hub (AI Integration):** Powered by Google Gemini API for advanced text generation and analysis.
- **Premium UI/UX:** Built with a "Midnight Obsidian" theme, featuring Glassmorphism, Bento-grids, and interactive hover effects.
- **Advanced Animations:** Smooth transitions and scroll effects powered by **Framer Motion**.
- **Secure Authentication:** Robust Login/Register system with JWT and neural presence initialization.
- **Theme Synchronicity:** Custom-built Theme Context for seamless Dark/Light mode transitions without hydration errors.

---

## 🛠️ Tech Stack

**Frontend:**

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion, Lucide React Icons
- **State Management:** React Context API (Custom Theme & Auth)

**Backend:**

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB
- **AI Engine:** Google Gemini API
